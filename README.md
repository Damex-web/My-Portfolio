# DCY Portfolio

A clean, simple, and responsive personal portfolio website built with **HTML5** and **CSS3**.

This project was created to showcase my work as a frontend developer, introduce myself, display my skills and projects, and make it easier for potential clients and collaborators to contact me.

The current version focuses on the structure, layout, and visual design using HTML and CSS. JavaScript functionality will be added in future updates.

## 🌐 Live Demo

**DCY Portfolio:**  
👉 [View Live Website](https://dcyportfolio.netlify.app)

## 🚀 Features

- Clean and modern user interface
- Fully responsive design
- Desktop, tablet, and mobile layouts
- Hero section with developer introduction
- About section
- Skills section
- Projects section
- Contact section
- Social media links
- Mobile navigation design
- Call-to-action buttons
- Project statistics
- Experience statistics
- Responsive profile image section

## 📱 Responsive Design

DCY Portfolio is designed to provide a good experience across different screen sizes.

- 💻 Desktop
- 📱 Mobile
- 📲 Tablet

The layout automatically adapts to smaller screens with a mobile-friendly navigation and responsive content.
